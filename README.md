This project was my first ever electronics project that I created after learning a lot of electronics fundamentals.

I used an ESP32, two Geared Motors, an Ultrasonic Sensor, a Servo Motor to create an RC Car with self-driving feature as well.

An ESP32 WebServer is used to control the car.

Although it is important to note that this isn't actually a "Car" as it doesn't have steering like a "Car" would have.
It is a "Differential-Drive Robot".
